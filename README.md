# 🎮 Dashboard de Vendas e Assinaturas Xbox Game Pass

## 📌 Sobre o projeto

Este projeto foi desenvolvido em Microsoft Excel com o objetivo de analisar dados de assinaturas do Xbox Game Pass, utilizando recursos de organização, tratamento e visualização de dados para transformar informações operacionais em indicadores de negócio.

A ferramenta reúne uma base de assinantes, cálculos auxiliares e um dashboard com foco na análise de vendas de planos, renovação automática e assinaturas adicionais, como EA Play e Minecraft Season Pass.

O projeto demonstra como o Excel pode ser utilizado para estruturar dados, responder perguntas de negócio e apoiar a análise de desempenho comercial.

## 🎯 Objetivos

O principal objetivo é analisar as informações relacionadas às assinaturas e vendas do Xbox Game Pass, buscando responder perguntas como:

- Qual é o valor total das vendas de assinaturas?
- Como as vendas se distribuem entre os planos disponíveis?
- Qual é a participação das assinaturas com renovação automática?
- Qual é o volume de vendas de assinaturas adicionais do EA Play?
- Qual é o volume de vendas do Minecraft Season Pass?
- Como os diferentes produtos e modalidades de assinatura contribuem para os resultados?

## 📊 Análises realizadas

### 1. Análise dos planos de assinatura

A base contém informações sobre diferentes planos do Xbox Game Pass:

- Core;
- Standard;
- Ultimate.

Esses dados permitem analisar a distribuição dos assinantes e os valores associados às diferentes modalidades de assinatura.

### 2. Análise da renovação automática

O projeto considera a informação de renovação automática de cada assinatura, permitindo segmentar os registros entre clientes com renovação ativada e desativada.

Essa análise pode ajudar a compreender a composição da base de assinantes e a importância da renovação automática para a continuidade das receitas.

### 3. Vendas de EA Play

A planilha contém informações sobre assinaturas adicionais do EA Play, incluindo a identificação da contratação e os valores associados ao produto.

A análise permite observar a contribuição desse serviço para o faturamento total registrado na base.

### 4. Vendas de Minecraft Season Pass

O projeto também contempla informações sobre o Minecraft Season Pass, possibilitando analisar os valores associados às assinaturas adicionais desse produto e sua distribuição entre os planos.

### 5. Análise dos valores das assinaturas

A base inclui preços de assinatura, valores de produtos adicionais e cupons de desconto, além de um campo de valor total.

Essas informações permitem organizar os componentes financeiros de cada registro e apoiar a análise dos valores das vendas.

## 🗂️ Estrutura do arquivo

O arquivo está organizado em quatro abas principais:

### `Assets`

Reúne elementos de apoio visual, como referências de cores e recursos utilizados na identidade visual do dashboard.

### `Bases`

Contém a base de dados das assinaturas, incluindo campos como:

- ID do assinante;
- Nome;
- Plano contratado;
- Data de início;
- Renovação automática;
- Preço da assinatura;
- Tipo de assinatura;
- Contratação e preço do EA Play Season Pass;
- Contratação e preço do Minecraft Season Pass;
- Valor de cupons;
- Valor total.

### `Cálculos`

Concentra análises auxiliares e tabelas de resumo utilizadas para responder perguntas de negócio sobre os valores das assinaturas e as vendas dos produtos adicionais.

### `Dashboard`

Apresenta a área visual do projeto, desenvolvida para reunir as informações de vendas e assinaturas em uma interface de acompanhamento dos indicadores.

## 🚀 Como utilizar

1. Faça o download do arquivo `dashboard-excel-vendas-xbox.xlsx` neste repositório.
2. Abra o arquivo no Microsoft Excel.
3. Consulte a aba `Bases` para conhecer os dados utilizados nas análises.
4. Acesse a aba `Cálculos` para visualizar os resumos e as análises auxiliares.
5. Consulte a aba `Dashboard` para acompanhar a apresentação visual do projeto.
6. Utilize as informações para explorar a composição das assinaturas e os valores registrados para os produtos.
